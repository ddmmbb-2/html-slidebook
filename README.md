# HTML Slidebook

**不用裝 PowerPoint，打開瀏覽器就能編輯、播放和帶走你的簡報。**

這個專案借鑑 TiddlyWiki 的單檔做法，把簡報內容、編輯器和播放器放在同一個 HTML 裡。做好後可以放進隨身碟、傳給同事，或帶到另一台電腦離線播放。收到的人雙擊檔案就能開啟，也可以接著編輯。

## 快速開始

1. 下載 `HTML-Slides.html`。如果拿到的是可攜版 ZIP，先解壓縮，再雙擊裡面的 HTML。
2. 點左側的「投影片範本」新增一頁。雙擊文字開始修改，也可以拖曳物件、調整大小或插入圖片、影片和音訊。
3. 點「播放」，用左右方向鍵換頁，按 `Esc` 退出。底部控制列會在開始播放或換頁時顯示 3 秒。滑鼠移到畫面底部，或用觸控點一下底部，就能叫回控制列。
4. 編輯完成後，點右上角的「另存新檔」。

## 怎麼帶走簡報？

| 另存方式 | 適合的情境 |
| --- | --- |
| **單一 HTML** | 將文字、圖片和影音一起存進 HTML，方便直接傳送或放進隨身碟。 |
| **HTML＋影音 ZIP** | 簡報有較大的影片或多個影音檔時，將 HTML 與 `media/` 資料夾打包。解壓縮後開啟 HTML，搬移時把兩者一起帶走。 |
| **覆蓋本機簡報（HTML＋媒體）** | 用電腦版 Chrome 或 Edge 開啟本機簡報，編輯後選取原 HTML 所在的資料夾並允許寫入。沿用原檔名，所需媒體直接存入旁邊的 `media/`。 |

已解壓縮的簡報可以直接使用「覆蓋本機簡報」。選定包含 HTML 的那一層資料夾並允許寫入後，編輯器會立即開始儲存。完成後會顯示成功訊息並關閉存檔視窗。原有的媒體檔會保留，新增的圖片、影片及音訊會寫入同一個 `media/` 資料夾。

若瀏覽器選完資料夾後未授予存取權，可從檔案總管把整個簡報資料夾拖進存檔視窗的拖放區。出現「允許寫入並儲存」時，按下按鈕並接受瀏覽器的寫入授權，即可儲存到剛拖入的資料夾。

要用新版工具繼續編輯舊簡報，先打開新版，再按「開啟簡報」選取原本的 HTML。若原檔引用獨立的影音資料夾，依提示選取原 HTML 所在的資料夾。

## 目前功能

- 內建 9 種範本，包含封面、章節頁、重點條列、雙欄比較、文字＋影音、操作步驟和提問與討論。
- 支援新增、複製、刪除與排序投影片，以及編輯操作的復原與重做。
- 在右側「投影片」設定，可為目前這一頁設定、更換或移除背景圖。圖片會等比例置中填滿頁面，並隨簡報一起另存。
- 插入的圖片可拖或放大到投影片邊緣之外。頁面只會顯示範圍內的部分，可利用這個方式擷取畫面中的角落或局部。
- 支援全螢幕播放，可分別設定編輯畫面與播放畫面是否顯示頁碼。
- 簡報以 `.html` 儲存，使用瀏覽器開啟。影音能否播放取決於瀏覽器支援的格式。

## 如何請 LLM 修改

把整個原始碼資料夾或原始碼 ZIP 交給 LLM，請它先讀 [AGENTS.md](AGENTS.md)。描述你想從哪個操作入口使用新功能、希望看到什麼結果，以及哪些現有操作要保留。最後請它驗證修改，並交付更新後的原始碼和可直接開啟的 `HTML-Slides.html`。

例如，可以這樣下指令：

> 請先讀 `AGENTS.md`。在「投影片範本」加入一個「課程複習」範本，包含標題、三個重點和一題討論題。請保留現有範本、另存方式與舊簡報相容性。修改後驗證範本能從選單新增，也能在另存、重新開啟後繼續編輯。請提供更新後的原始碼和可離線開啟的 `HTML-Slides.html`。

### 原始碼如何方便 LLM 接手

- **依功能分檔。** 編輯、播放、影音和匯出各有獨立的模組。改播放控制列可從 `src/playback.mjs` 著手，新增預設範本則可直接在 `src/slide-templates.json` 加一筆。
- **資料欄位有固定契約。** `AGENTS.md` 說明投影片、物件、影音引用和座標的格式，讓 LLM 能沿用既有欄位，也知道該保留哪些舊檔相容行為。
- **可用測試回查修改。** 內建測試涵蓋編輯、播放、匯出和舊檔相容等流程。請 LLM 驗證這次改動，也順手檢查相關功能。
- **分檔維護，單檔交付。** 原始碼拆開方便修改，交付時組成一個 HTML。使用者雙擊檔案即可離線編輯和播放。
