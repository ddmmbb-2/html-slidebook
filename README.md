# HTML Slidebook

**不用裝 PowerPoint，打開瀏覽器就能編輯、播放和帶走你的簡報。**

這個專案借鑑 TiddlyWiki 的單檔做法，把簡報內容、編輯器和播放器放在同一個 HTML 裡。做好後可以放進隨身碟、傳給同事，或帶到另一台電腦離線播放。收到的人雙擊檔案就能開啟，也可以接著編輯。

## 快速開始

1. 下載 `HTML-Slides.html`。如果拿到的是可攜版 ZIP，先解壓縮，再雙擊裡面的 HTML。
2. 點左側的「投影片範本」新增一頁。雙擊文字開始修改，也可以拖曳物件、調整大小或插入圖片、影片和音訊。
3. 點「播放」，用左右方向鍵換頁，按 `Esc` 退出。底部控制列會在開始播放或換頁時顯示 3 秒。滑鼠移到畫面底部，或用觸控點一下底部，就能叫回控制列。
4. 編輯完成後，點右上角的「另存新檔」。

## 怎麼帶走簡報？

| 另存方式 | 適合的情境 |
| --- | --- |
| **單一 HTML** | 將文字、圖片和影音一起存進 HTML，方便直接傳送或放進隨身碟。 |
| **HTML＋影音 ZIP** | 簡報有較大的影片或多個影音檔時，將 HTML 與 `media/` 資料夾打包。解壓縮後開啟 HTML，搬移時把兩者一起帶走。 |

要用新版工具繼續編輯舊簡報，先打開新版，再按「開啟簡報」選取原本的 HTML。若原檔引用獨立的影音資料夾，依提示選取原 HTML 所在的資料夾。

## 目前功能

- 內建 9 種範本，包含封面、章節頁、重點條列、雙欄比較、文字＋影音、操作步驟和提問與討論。
- 支援新增、複製、刪除與排序投影片，以及編輯操作的復原與重做。
- 支援全螢幕播放，可分別設定編輯畫面與播放畫面是否顯示頁碼。
- 簡報以 `.html` 儲存，使用瀏覽器開啟。影音能否播放取決於瀏覽器支援的格式。

## 從原始碼建置

使用 Python 3 產生單一 HTML。建置無須安裝 npm 套件，也無須啟動本機伺服器。

```sh
python build.py
```

建置後，在瀏覽器開啟產生的 `HTML-Slides.html`。要執行自動測試，請使用 Node.js 22 或更新版本及 Python 3。

```sh
node --test
```

原始碼位於 `src/`。要擴充投影片範本，可編輯 `src/slide-templates.json` 後重新建置。模組入口、資料格式與維護說明見 [AGENTS.md](AGENTS.md)。

## 關於開發

本專案由作者提出需求，使用 AI 協助實作、重構與撰寫測試。原始碼採分檔模組化，方便後續用 AI 定位功能、修改程式與執行回歸測試。發布時再把各模組打包成單一 HTML，讓簡報可以離線使用和攜帶。
